# Spec Summary (Lite)

Give tasks real structure - subtasks, tags, repeats, a three-column board - and feed that
structure to the RPG layer without ever letting it grant experience. Phase 1 (task model)
and Phase 2 (adventurer strip) have shipped; Phases 3-8 cover items and affixes, content
and bestiary, encounter depth, tasks-as-monsters, and the long game.

Six competing subsystem designs contained twelve direct contradictions, four indirect XP
leaks and one live exploit. This spec records the ruling on each, so the unbuilt phases are
executable rather than merely imagined.
